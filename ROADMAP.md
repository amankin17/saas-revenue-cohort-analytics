# Iterative development roadmap

These are **future milestones**, not a claim that previous months of work have happened. Record actual dates as you complete them.

| Stage | Focus | Acceptance criteria |
|---|---|---|
| Month 1 | Baseline & quality | Reproduce baseline outputs; tests and documentation pass |
| Month 2 | Deeper analysis | Add a new model, segment, or evaluation metric with clear evidence |
| Month 3 | Decision-ready product | Package findings into a dashboard/report, document limitations, and demo to a reviewer |

Use GitHub issues/milestones to track progress from the real start date; publish commits when work is done.
